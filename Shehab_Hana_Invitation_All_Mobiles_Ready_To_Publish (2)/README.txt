Shehab & Hana – Universal Mobile Invitation

Publish this folder to an HTTPS website. Recommended: open https://app.netlify.com/drop and drag the ZIP or the unzipped folder, then share the generated HTTPS URL. Do not share index.html as an attachment, as iOS WhatsApp/Files previews can block audio and links.

Guests must tap افتحوا دعوتنا to start the music: iOS/Android do not allow silent autoplay without a real user gesture.

If Maps is blocked inside an in-app browser, there is an Apple Maps fallback and a Copy Venue option on the final card.
